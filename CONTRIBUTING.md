# Contributing

This repository is maintained as a professional PHP inventory and POS portfolio project.

## Quality Bar

Before submitting changes:

- Keep role-based access clear.
- Do not commit credentials or local configuration.
- Update documentation when setup changes.
- Add tests for business-critical logic where practical.
- Keep database changes documented.

## Pull Request Checklist

- Summary of the change
- Testing notes
- Screenshots for UI changes
- Database notes, if relevant
- Known limitations
